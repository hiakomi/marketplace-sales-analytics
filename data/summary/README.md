# Сохранённые агрегаты исследования

`summary.json` — единый снимок числовых результатов для графиков и CSV. Он содержит именованные поля и метаданные. Это **исторические агрегаты**, зафиксированные в материалах 26.09.2026, а не текущий пересчёт рабочей базы.

- Период: `[2023-01-01, 2024-01-01)`, фильтр `quantity > 0`.
- Источники: [отчёты и презентации](../../reports/README.md), итоговые сводки исследования от 26.09.2026.
- Денежная единица в источнике обозначена как рубли. Учебный масштаб требует проверки перед бизнес-применением.
- Поле `snapshot_documented_on` означает дату фиксации материалов, а не известную дату запуска SQL. Отдельного журнала этого запуска нет.
- Сырые продажи, персональные данные и реквизиты подключения сюда не входят.

## Файлы и поля

| Файл | Что содержит |
|---|---|
| [summary.json](summary.json) | Метаданные и все именованные записи |
| [assortment_actions.csv](assortment_actions.csv) | Группа, число SKU, доли SKU, выручки и единиц |
| [discount_actions.csv](discount_actions.csv) | Скидочная группа, число SKU, доли SKU и выручки |
| [abc_revenue.csv](abc_revenue.csv) | Класс ABC по выручке, число и доля SKU, приблизительная доля выручки |
| [rfm_segments.csv](rfm_segments.csv) | Пять ключевых сегментов, доли клиентов и выручки |
| [repeat_rate.csv](repeat_rate.csv) | Окно, подходящая выборка, повторившие клиенты и процент |
| [cohort_metrics.csv](cohort_metrics.csv) | M0–M6, исходная численность, retention и денежные показатели |

Поля с суффиксом `_pct` содержат проценты: `15.19` означает 15,19%, а не 0,1519. Денежные поля содержат суммы в единицах источника, без деления на тысячи или миллионы. В JSON `null`, а в CSV пустая ячейка означают **неизвестное значение**, а не ноль.

`summary.json` дополнительно сохраняет девять сочетаний двойного ABC и полное распределение частоты активных дней. Значения не детализированы до конкретных клиентов или товаров.

## Границы воспроизводимости

| Группа данных | Связь с SQL |
|---|---|
| ABC, двойной ABC, RFM, repeat rate, LTV | В репозитории есть соответствующие запросы; новый запуск на рабочей базе при публикации не проводился |
| Retention | Сохранены прежние цифры. Изменения обработки нулевых месяцев проверяются отдельно на синтетических данных |
| Девять ассортиментных групп действий | Финальные CASE-правила и полный список product_id отсутствуют |
| Четыре скидочные группы действий | Финальные CASE-правила отсутствуют |

Девять групп действий не равны девяти сочетаниям двойного ABC. Полный CA содержит 7 706 SKU, группа «Массовые недорогие товары» — 7 275. Старый отбор пяти CCZ-кандидатов не воспроизводит 184 SKU нового приоритетного ревью.

Для «Потенциала роста» и «Низкого приоритета» доля выручки не указана. Не распределяйте между ними остаток выручки предположениями. Проценты округлены; их сумма может немного отличаться от 100%.

RFM содержит пять из 11 сегментов и не является полным распределением. Кроме ценных неактивных, доли сохранены с округлением до 0,1 п. п. Выборки repeat rate различаются между окнами. Когортная таблица использует 630 187 исходных клиентов января–июня во всех точках M0–M6.

## Повторное построение CSV и графиков

```bash
python -m pip install -r requirements-visuals.txt
python scripts/build_summary_assets.py
```

Запускайте команды из корня репозитория. Скрипт читает только локальный JSON, формирует шесть CSV и три PNG в `docs/images/`, без API и подключения к PostgreSQL. Это воспроизведение визуализаций сохранённых чисел, а не пересчёт исследования.
