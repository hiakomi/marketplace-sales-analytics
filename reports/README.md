# Презентации и подробные отчёты

Материалы исследования продаж за 2023 год, подготовленные по сохранённым результатам 26.09.2026. Для чтения прямо на GitHub доступны две страницы исследований; редактируемые файлы можно скачать отдельно.

| Направление | Читать на GitHub | Презентация, 14 слайдов | Отчёт, 8 страниц |
|---|---|---|---|
| Ассортимент | [Исследование](../docs/analysis/assortment.md) | [PPTX](assortment/assortment-presentation.pptx) | [DOCX](assortment/assortment-report.docx) |
| Клиенты и LTV | [Исследование](../docs/analysis/customers.md) | [PPTX](customers/customers-presentation.pptx) | [DOCX](customers/customers-report.docx) |

В презентациях 12 основных слайдов и два методических приложения. Текст, таблицы и диаграммы редактируются; заметки содержат пояснения и источники.

Файлы опубликованы в исходной подготовленной версии. Новые страницы GitHub уточняют связь с текущими запросами и статус воспроизводимости. При изменении SQL исторические цифры не подменяются результатами синтетических тестов: для обновления нужен отдельный пересчёт исходной базы.

Упоминаемые внутри файлов `01_assortment_original.sql` и `02_clients_original.sql` соответствуют исходным блокам, которые в репозитории разделены на [16 ассортиментных](../sql/README.md#ассортимент) и [14 клиентских](../sql/README.md#клиентская-база) запросов. Их подготовка и уточнение фильтров описаны в [журнале](../docs/preparation-notes.md).

Новые группы `assortment_action` и `discount_action`, включая 184 SKU приоритетной ревизии, сохранены как агрегаты. Финальные CASE-правила отсутствуют. Старый SQL-отбор пяти CCZ-товаров имеет другую логику. Подробнее — в [исследовании ассортимента](../docs/analysis/assortment.md) и [описании данных](../data/summary/README.md).
